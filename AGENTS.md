# Desktop mockup

This is the GitHub Pages version of the macOS desktop mockup. Keep assets relative to import.meta.env.BASE_URL so the published project subdirectory works. Run npm run build before pushing. GitHub Pages deploys automatically from main.

Preserve the selected dark graphite/platinum visual direction, native macOS artwork, glass surfaces, and desktop-first layout. The login and system actions are browser-local simulations. Never send or persist anything typed in the demo password field. Native system actions such as sleep, restart, and shutdown must only affect this webpage.

Keep new UI in focused components and use Phosphor icons or supplied raster artwork. Preserve the polished login-to-desktop flow and keyboard access.
